# Performance report: M6, 2026-11-12

Written by `pnpm perf` (scripts/perf/) against the budgets in [rendering.md §2](../plan/rendering.md#2-performance-budget). **Every budget is met.**

## Setup

- **Machine:** Mac16,5, Apple M4 Max, 128 GB, macOS 26.6.2.
- **Code:** commit `a43991f` plus uncommitted changes; a production build with the test hooks (`VITE_TEST_HOOKS=1`).
- **Browsers:** chrome 157.0.8103.51; webkit 27.2. Headed, 1440 × 900 CSS px at device pixel ratio 2, default quality (Medium: DPR capped at 1.5).
- **Timers:** WebKit rounds `performance.now()` to whole milliseconds, so its frame times carry ±1 ms; the 60 fps check allows it that, and its label timings aren't judged.
- **Display refresh rate, measured:** chrome 238 Hz, webkit 59 Hz. Frame intervals can't be shorter than the display's.
- **Mode:** view mode, as a reader sees it.
- **Content:** the stress map, 5,000 objects (300 groups and 50 routes are drawn from M4).
- **Path:** load; 3 s idle; orbit (3 left-drags); pan (2 right-drags); zoom toward the cursor (100 wheel steps at two points); orbit again holding Space (every label shown). Then the system view: the map's first system made busy (1 star, 12 planets, one ringed, 2 belts, 5 stations); 3 timed entries and exits; orbit (3 left-drags) and zoom (48 wheel steps over empty space) inside it; 20 more round trips; then 20 galaxy → system → orbit round trips through an explorable planet with a moon. 3 s idle after each phase. Pointer steps are 16 ms apart.
