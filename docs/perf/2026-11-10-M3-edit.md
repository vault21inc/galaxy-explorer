# Performance report: M3, 2026-11-10

Written by `pnpm perf` (scripts/perf/) against the budgets in [rendering.md §2](../plan/rendering.md#2-performance-budget). **Every budget is met.**

## Setup

- **Machine:** Mac16,5, Apple M4 Max, 128 GB, macOS 26.6.2.
- **Code:** commit `75f1c0c`; a production build with the test hooks (`VITE_TEST_HOOKS=1`).
- **Browsers:** chrome 157.0.8103.39; webkit 27.2. Headed, 1440 × 900 CSS px at device pixel ratio 2, default quality (Medium: DPR capped at 1.5).
- **Timers:** WebKit rounds `performance.now()` to whole milliseconds, so its frame times carry ±1 ms; the 60 fps check allows it that, and its label timings aren't judged.
- **Note:** the run was made just before `75f1c0c` was committed, with the app at `21b8e87` (the commit only adds `--edit` to scripts/perf/). Chrome's window opened on the 240 Hz external display, not the built-in reference display.
- **Display refresh rate, measured:** chrome 238 Hz, webkit 59 Hz. Frame intervals can't be shorter than the display's.
- **Mode:** edit mode, with the reference underlay shown (drawn in every run) and 100 selected / 100 selected; left-drags orbit with Alt held, as edit mode requires.
- **Content:** the stress map, 5,000 objects (300 groups and 50 routes are drawn from M4).
- **Path:** load; 3 s idle; orbit (3 left-drags); pan (2 right-drags); zoom toward the cursor (100 wheel steps at two points); orbit again holding Space (every label shown). 3 s idle after each phase. Pointer steps are 16 ms apart.
